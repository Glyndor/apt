# line, three fields separated by TAB:
#
#   file <TAB> a text that occurs exactly once in that file <TAB> the reason
#
# The text lies somewhere on the lines of the refusal: its condition, the header
# of the block that holds it, or the refusal itself. A text of `*` exempts every
# refusal of the file.
#
# scripts/quality/check-mutation-coverage.sh fails when a refusal of a script it
# watches has neither an entry nor a line here, and when a line here has
# outlived its premise: its text is gone, it reaches no refusal, or an entry now
# covers what it exempts. A line is retired by writing the entry, or the test
# that makes an entry possible, and deleting the line in the same change.
